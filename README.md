# Valutazione raggruppamenti

Strumento che, dato un bando con i suoi requisiti di partecipazione e un
raggruppamento di piu imprese con i rispettivi fascicoli, indica chi copre
cosa, quanto manca e come diventare ammissibili.

Progetto personale a scopo dimostrativo, non affiliato a Cato. I dati
utilizzati sono di esempio.

Stack: Vite, React, TypeScript. Nessun backend: il motore di valutazione e
una funzione pura, coperta da test.
